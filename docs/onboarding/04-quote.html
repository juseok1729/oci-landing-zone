견적서 읽는 법 (교육용)

실무 견적서는 요약 (1쪽) → OCI 리소스 상세 → 인건비 상세 → MSP 범위 순서로 구성된다. 고객은 요약만 보고, 검토 담당자는 상세에서 빠진 항목과 계산을 확인한다.

항목읽는 법
월 비용 계산Part Qty × Instance Qty × Usage Qty × Unit Price. Part Qty 는 한 대의 양 (OCPU 수, GB), Instance Qty 는 대수 · 노드 수, Usage Qty 는 시간 과금이면 월 730시간, 월 과금이면 1 이다. e.g., 운영 WEB OCPU: 2 × 2 × 730 × $0.03 = $87.60 → × 1,450 = 127,020원.
원화 · 연간달러 금액 × 고정 환율 = 월 원화, × 12 = 연간. 환율은 Oracle 이 정한 고정 환율을 쓰고 견적서에 꼭 적는다.
Block Volume용량 (GB) 과 성능 단위 (VPU) 를 따로 과금한다. Balanced 는 GB 당 10 VPU 라서 100GB 면 Performance Units 1,000 이다.
0원 항목Bastion, Cloud Guard, DRG, VPN, 월 10TB 전송은 무료지만 "검토했다" 는 표시로 적는다. 빠져 있으면 고객이 누락으로 본다.
RFP 와의 연결물량은 RFP ECR-002~004, 산정 근거 제출은 ECR-005 다. 입찰가는 구축비 (VAT 포함 387,750,000원) 이고 예산 6억 원 (VAT 포함) 안이다. UC 는 발주기관 직접 계약 항목이라 참고 금액이다.
M/M한 사람이 한 달 일한 양. 6개월 사업에 PM 6 M/M 은 PM 이 기간 내내 투입된다는 뜻이다. 구축비 = Σ (M/M × 역할별 단가) + 외주 (모의해킹).
MSP오픈 후 운영 기술지원. UC 의 일정 비율 (이 예시는 10%) 로 산정한다. 무상 하자보수는 구축 결과의 결함을 고치는 것이고, MSP 는 일상 운영을 맡는 별도 계약이다.
자동 확장견적은 최소 대수 기준이다. 피크에 늘어나는 비용 (WEB 대당 월 103,544원) 은 조건으로 적어 둔다.
단가 · 환율 · 인건비 단가 · MSP 요율은 모두 교육용 예시다. 실제 견적은 OCI 가격표와 Oracle 고정 환율을 다시 확인하고, 할인 · 인건비 단가 · 요율은 영업 승인을 받은 값을 쓴다.
